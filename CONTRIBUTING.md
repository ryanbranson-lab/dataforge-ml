# Contributing

Python 3.12+; run the README tests, lint and strict type checks from this directory.
Use focused feature branches and issues with explicit acceptance criteria. Include
actual tests, risks and limitations in PRs; obtain genuine independent review
before merge. Dependency changes require a reason and license review.

Repository owner: `ryanbranson-lab`. This initial code was prepared by Codex with the
account owner's authorization. Commits identify the AI assistant explicitly;
repository ownership and authenticated pushes do not imply independent human
implementation or review. Do not rotate accounts to fabricate collaboration,
coauthors or approvals. No historical activity is backdated.

No release, paid service or production deployment without explicit approval.
